Команда: **Саня (капитан), Рамазан, Матвей, Данил**. Арслан в проекте больше не участвует.
Даты чекпоинтов не известны: задачи упорядочены по приоритету, реальные сроки впишите, когда узнаете.
Перед каждым Pull Request: `bash run_tests.sh` (все тесты сразу).

## Требования организаторов

| Требование | Что делаем |
|---|---|
| Проверка на Qwen 27B или 35B (ключ должны были выдать, Саня выясняет) | Целевая модель. Подключение через `LLM_PROVIDER=openai` + ключ. Блоки `<think>` снимаются в `core/llm.py` |
| История диалога (сейчас сохраняются только датасеты) | Данил: чаты в Postgres + список чатов в интерфейсе |
| Модель не должна путаться на нескольких датасетах | Матвей: понятие «датасет»; Рамазан: проверочный набор |
| Качество важнее числа сценариев | Новые сценарии заморожены, всё усилие на точность и честные отказы |
| Скорость | Сначала замеры, потом убираем лишние вызовы модели и пересчёты |

## Статус

**Готово и в `dev`:** репозиторий и ветки; план; `uv`, зависимости и Dockerfile под `uv`; загрузчик (десятичная запятая, потоковая загрузка `load_csv_to_postgres`, метод `Database.load_csv`); связи без ложных совпадений; каркас аналитики и `analyze_unknown_csv`; `docker-compose.yml` с профилями `gpu`/`cpu` и надёжной автозагрузкой модели, `run.sh`, `.dockerignore`, `core/llm.py` (честный статус модели, понятные ошибки, снятие `<think>`, `LLM_KEEP_ALIVE`, `LLM_EXTRA_PARAMS`), лёгкий `profile_all`, `run_tests.sh`.

**Ещё не сделано:**
- `app.py` по-прежнему грузит файлы старым путём (`db.load_dataframe(read_csv_smart(...))`), быстрая загрузка в нём не подключена;
- нет `.streamlit/config.toml` (лимит загрузки Streamlit 200 МБ);
- блок «Детальный анализ» в `app.py` ничего не показывает: ключ `analysis` нигде не записывается;
- ни разу не проверено с моделью Qwen 27/35B.
